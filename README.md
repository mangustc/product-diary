# Product Diary

## Основная информация о проекте

Цель - создание веб-сайта, позволяющего добавлять продукты (калорийность, БЖУ, название) в реестр продуктов, и использовать этот реестр продуктов для аналитики своих затрат и долга части от цены продукта к другим людям.

Тип продукта - веб-сайт.

[Требования и функционал](./REQUIREMENTS.md)

## Использованные технологии

В проекте на данный момент реализовано:

- **API на основе net/http**: API на базе стандартной библиотеки Go net/http
- **HTMX и Templ**: клиентская часть реализована на библиотеке HTMX, а Templ выступает в роли шаблонизатора HTML для Go
- **Локализатор сообщений**: простой кастомный type-safe локализатор, EN/RU
- **Middleware**: кастомный Middleware на базе стандартной библиотеки Go net/http
- **Логгер**: простой кастомный логгер для вывода сообщений различных типов в stdout

## Структура кода

В проекте используется **Dependency injection**, что позволяет отделить внутреннию логику реализации структур от ее внешней логики.

В самом корне программы лежит [main.go](cmd/main.go). Он создает необходимо объекты: DB, Service, Handler. Затем к этим объектам привязываются соответствующие API-запросы, и запускается API с Middleware.

Деление происходит по группам объектов (item - экземпляр продукта, product - продукт, user - пользователь) следующим образом:

- **Handler** принимает запросы, выполняет различные манипуляции с информацией и возвращает ответ
- **Service** предоставляет базовые функции работы с группой объектов. Только Service может вызывать функции БД
- **DB** играет роль интерфейса взаимодействия с базой данных
