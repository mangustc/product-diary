# Product Diary

## Основная информация о проекте

Цель - создание веб-сайта, позволяющего добавлять продукты (калорийность, БЖУ, название) в реестр продуктов, и использовать этот реестр продуктов для аналитики своих затрат и долга части от цены продукта к другим людям.

Тип продукта - веб-сайт.

[Требования и функционал](./REQUIREMENTS.md)

## Использованные технологии

В проекте на данный момент реализовано:

- **API на основе net/http**: API на базе стандартной библиотеки Go net/http
- **HTMX и Templ**: клиентская часть реализована на библиотеке HTMX, а Templ выступает в роли шаблонизатора HTML для Go
- **Локализатор сообщений**: простой кастомный type-safe локализатор, EN/RU
- **Middleware**: кастомный Middleware на базе стандартной библиотеки Go net/http
